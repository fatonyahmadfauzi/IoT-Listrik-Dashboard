IoT Listrik Dashboard — Catatan Release

Release terbaru: v1.1.6 (1 September 2026)

- Perbaikan encoding label metrik Telegram agar tidak tampil sebagai karakter mojibake.
- Alarm Web/PWA dan Windows berhenti ketika telemetry berhenti atau perangkat offline.
- Alarm Android dipusatkan pada foreground service sehingga suara, getaran, notifikasi, dan layar dapat dihentikan konsisten.
- Backend mengirim perintah STOP_ALARM ketika perangkat terdeteksi offline.
- Android APK, Windows Setup, Portable, MSI, CLI Node.js, CLI Python, dan CLI Linux dibangun untuk release v1.1.6.
- Halaman Downloads diarahkan ke seluruh aset release v1.1.6.

Rujuk CHANGELOG.md untuk riwayat lengkap perubahan.
