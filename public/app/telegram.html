send Konfigurasi Telegram
Aman: Token dan daftar Chat ID disimpan di Firebase — bukan di firmware. Hanya admin yang dapat mengubahnya. ESP32 membaca nilai ini setiap sinkronisasi.
Dapat dari @BotFather → /newbot → copy token.
Command personal per Chat ID: setiap penerima yang sudah terdaftar bisa mengirim /pause, /resume, /status, dan /help ke bot yang sama. Perintah hanya berlaku untuk chat tersebut, jadi penerima lain tidak ikut terpengaruh.
Tambahkan satu atau lebih tujuan. Untuk grup: awali dengan -100. Untuk pribadi: ID numerik positif.
Cara cek: kirim pesan ke @iot_kebocoran_bot → buka api.telegram.org/bot<TOKEN>/getUpdates
